# ADR 0002: 클라이언트 아트 방향

- 상태: 승인
- 날짜: 2026-11-03

## 배경
포트폴리오의 핵심은 서버다. 클라이언트 작업은 전체 시간의 10~15%로 제한한다.
도트 2.5D(3D 배경 + 도트 캐릭터 빌보드)도 검토했지만, 방향별 스프라이트·3D 환경·조명 작업이 커서 8주 일정에는 위험하다.

## 결정
- **~12/31:** 2D 탑다운 도트 그래픽
  - Unity URP 2D Renderer, Pixel Perfect Camera, Y축 정렬, 2D Light로 입체감 연출
  - 이펙트: [pixelfx](https://github.com/patch-gg/pixelfx) (MIT)에서 스프라이트 시트로 내보내서 사용. 새 이펙트 제작에 시간을 쓰지 않는다
  - 캐릭터·타일·UI: 상업 이용 가능한 무료 에셋 (라이선스를 하나씩 확인하고 THIRD_PARTY_NOTICES에 기록)
- **1월 이후 (선택):** 클라이언트만 2.5D로 교체
- **서버 좌표계:** 렌더링 방식과 무관하게 바닥 평면 (x, y) + 방향만 사용한다. 2D에서 2.5D로 바꿔도 서버와 프로토콜은 변경하지 않는 것이 목표다

## 결과
- 클라이언트 작업량을 통제하면서도 시연 영상은 그럴듯하게 나온다
- 렌더링을 바꿔도 서버를 고치지 않는다는 것이 서버·클라이언트 관심사 분리의 근거가 된다
- 특정 게임의 캐릭터, UI 배치, 세계관은 따라 하지 않는다. 그림체만 참고한다
